# 🍕 Pizzaria — Projeto Educacional

Projeto de desenvolvimento de um site para uma **pizzaria**, criado como atividade educacional durante o curso do **SENAI**.

O objetivo do projeto é colocar em prática conhecimentos de desenvolvimento web, organização de páginas, estruturação de conteúdo e trabalho em equipe.

---

## 📚 Sobre o projeto

Este projeto consiste na criação de um site para uma pizzaria fictícia, desenvolvido em grupo como parte das atividades do curso.

A proposta é criar uma experiência simples e agradável para que o usuário possa conhecer a pizzaria, visualizar seus produtos e navegar pelas diferentes páginas do site.

O projeto possui **finalidade exclusivamente educacional** e foi desenvolvido para fins de aprendizado e prática.

## 🎯 Objetivos

- Praticar desenvolvimento de páginas web;
- Aprender a organizar a estrutura de um projeto;
- Desenvolver uma interface para uma pizzaria;
- Aplicar conhecimentos de HTML e CSS;
- Trabalhar em equipe utilizando Git e GitHub;
- Aprender conceitos de organização e versionamento de código.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas;
- **CSS3** — estilização e layout;
- **Git** — controle de versão;
- **GitHub** — hospedagem e colaboração no projeto.
